# Changesets

This folder is managed by `@changesets/cli`, a tool that helps version and
publish this package. Each change gets a Markdown file describing the bump
level (major, minor, patch) and a summary. Running `changeset version`
consumes them into `CHANGELOG.md` and bumps `package.json`'s version.

See the full documentation at [changesets/changesets](https://github.com/changesets/changesets).
