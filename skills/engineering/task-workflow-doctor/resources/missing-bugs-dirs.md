# Missing `docs/bugs/` and `docs/bugs/archive/`

## Symptom

- Cannot create bugs.
- Cannot archive fixed bugs.
- `/skill:report-bug` or a bug ticket's close-out fails because bug directories are missing.

## Missing artifact

- `docs/bugs/`
- `docs/bugs/archive/`

## Route

Run `/skill:setup-workflow` to create the bugs directory structure.
