# Missing `docs/tasks/` tree

## Symptom

- Tasks are not showing up.
- `docs/tasks/` is missing or empty.
- `/skill:wayfinder` or `/skill:implement-task` cannot find task files.

## Missing artifact

The `docs/tasks/` directory tree, including `docs/tasks/archive/` and `docs/tasks/maps/archive/`.

## Route

Run `/skill:onboard-workflow` to create the task directory structure.
