# Productivity

General workflow tools, not code-specific. **Promoted**: shipped (in
`package.json` `pi.skills`) and each gets a human-facing docs page at
`docs/productivity/<name>.md`.

## User-invoked

Reachable only when you type them (`disable-model-invocation: true`).

- **[grill-me](./grill-me/SKILL.md)**: The stateless interview: stress-test
  an idea without building a `CONTEXT.md` or saving anything locally.
- **[handoff](./handoff/SKILL.md)**: Compact the conversation into a handoff
  document so a fresh agent can pick the work up.
- **[teach](./teach/SKILL.md)**: Learn a concept over multiple sessions,
  from where you are to where you want to be.
- **[wait-what](./wait-what/SKILL.md)**: Stop. That last message did not
  land: re-pitch it.

## Model-invoked

Model- or user-reachable.

- **[to-questionnaire](./to-questionnaire/SKILL.md)**: Turn a decision you
  cannot answer alone into a questionnaire for someone else.
- **[writing-for-agents](./writing-for-agents/SKILL.md)**: The reference for
  writing documents agents consume.
